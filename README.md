# Wedding Landing Page

A responsive single-page wedding website built with HTML5 and CSS3.

## Features

- **Mobile-first responsive design** with breakpoints for tablet and desktop
- **Flexbox-based centering** for hero text and footer
- **Custom typography** using Google Fonts (Great Vibes, Libre Baskerville, Muli)
- **Semantic HTML5** structure
- **Pure CSS** — no JavaScript or frameworks

## Sections

- Hero (cover image with overlay)
- Locations (ceremony, photos, party)
- Program (event timeline)
- Gifts
- FAQ (questions & answers)
- Contact

## Tech stack

- HTML5
- CSS3 (Flexbox, media queries, `hsla()` for translucent overlays)
- [Meyer Reset](https://meyerweb.com/eric/tools/css/reset/) for cross-browser baseline
- [Google Fonts](https://fonts.google.com/)
